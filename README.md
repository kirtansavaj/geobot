# geobot
!!
A TypeScript-powered geographic bot application with an interactive HTML interface.

## 🌍 About

Geobot is a project that combines TypeScript and HTML to provide geographic information and utilities. This repository contains the core bot logic and web interface for geographic operations.

## 🛠️ Technology Stack

- **TypeScript** (69.4%) - Primary language for bot logic and backend functionality
- **HTML** (30.6%) - Frontend interface and markup

## 📋 Prerequisites

- Node.js (v14 or higher)
- npm or yarn package manager

## 🚀 Getting Started

### Installation

1. Clone the repository:
```bash
git clone https://github.com/kirtansavaj/geobot.git
cd geobot
```

2. Install dependencies:
```bash
npm install
```

### Development

To start the development environment:
```bash
npm run dev
```

### Build

To build the project:
```bash
npm run build
```
